# 拷贝路径 (copy-path) — 思源笔记插件

在思源笔记左侧文档树中右键**单个文档**时，把该文档的完整路径（格式 `/笔记本名/父文档/文档名`）拷贝到剪贴板，并短暂弹出所拷贝的内容。

## 安装

1. 下载或构建本插件，得到包含 `plugin.json`、`index.js`、`i18n/` 的插件目录。
2. 将整个目录放入思源笔记工作空间的 `data/plugins/copy-path/` 下。
3. 重启思源笔记（或在「设置 ▸ 集成 ▸ 插件」中重新载入），在插件市场中启用「拷贝路径」。

## 用法

1. 在左侧文档树中右键某个文档。
2. 在弹出的菜单中选择「插件 ▸ 拷贝路径」。
3. 该文档的完整路径即被写入剪贴板，屏幕上会短暂显示所拷贝的路径。

## 提示

- 插件菜单位于右键菜单的「插件 ▸」子菜单中，这是思源笔记对插件菜单项的统一收纳方式。
- 需要思源笔记 v3.0.0 及以上版本。
